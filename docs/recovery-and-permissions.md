# 有限恢复、权限与人工验收

本说明适用于“山间专注 · 协作试验”的独立测试项目。本文版本 1，依据共享文档固定快照 revision 1、《V0.5 协作与交付约定》版本 1（验证标识 workspace-v05）。本轮采用 V07-A 固定输入 3e9f13b8684680794dc10642c9bfe4203d42bdd5。

## 异常退出后能恢复什么

可信协调器再次启动任务时，执行者先读取任务、已选决定、恢复信息和固定输入，核对当前工作区已有成果，再从保留的文件继续，只修复剩余问题，避免重复添加功能或推翻已选文案。恢复后重新运行本地测试与构建，记录真实结果。

这是有限恢复：只能继续仍保存在工作区或固定输入中的成果，不能保证找回尚未写入文件的改动，也不承诺所有异常都能自动修复。页面计数仅存在于当前页面内存中，刷新或重新打开后，计数和累计操作次数均归零；任务恢复不会恢复上一次页面的计数。

本轮只提供本地文件、Shell 和 Node 内置测试，不提供连接的应用或浏览器。执行者不会尝试恢复插件或扩大权限。若后续步骤确实需要本人恢复连接、登录或身份验证，应保留已完成成果，说明剩余步骤，交由本人处理；恢复后仅继续剩余步骤。缺少浏览器连接不影响本轮本地整合，也不能视为已完成浏览器验收。

## 方案选择与执行权限

已选方案只决定该问题的产品内容。例如选择提示文案，只授权实现对应文案。不能把普通方案选择当作付费、删除重要文件、发布的授权，也不能据此读取凭据、修改权限或操作正式项目。

当前任务禁止付费 API、网络操作、安装依赖、调用其他 Agent、Git 提交或推送或合并，以及修改受保护文件。普通方案选择不会解除这些限制。新产品问题需要本人决定时，通过任务规定的结构化决策请求提交并结束本轮，收到选择后再继续。

## 本地检查与人工验收

自动化测试执行实际页面脚本和按钮处理函数，核对摘要、计数及累计操作次数的同步，并覆盖专注切换、图片失败与恢复；素材检查与构建检查核对实际交付文件。测试通过只能说明这些检查成功，不能代替视觉、真实键盘操作或本人的最终验收。

本人可在浏览器打开 index.html，或在可信交付桥提供预览后，按以下顺序验收：

1. 初始读数和累计操作均为 0，摘要为“当前计数：0；累计操作：0”。项目说明、“先记录，再推进”和“先验证，再扩展”均可见，山水图片正常展示。
2. 依次点击「−1」「+10」「+1」，计数应依次为 -1、9、10，累计操作应依次为 1、2、3；每步摘要与两个读数一致。
3. 点击「专注模式」，山景隐藏，读数和按钮放大，计数仍为 10、累计操作仍为 3，两条文案和摘要保持可见。点击「重置」两次后，计数为 0、累计操作为 5，摘要同步；点击「恢复普通布局」后山景恢复，操作次数仍为 5。
4. 用 Tab 聚焦按钮，以 Enter 和空格操作，确认焦点清晰且每次操作只计一次。在手机窄屏和短横屏检查文字、摘要和按钮可读可操作，必要时能滚动。
5. 图片加载失败时应出现占位，计数和专注切换继续可用；图片恢复加载后占位消失。刷新页面，两个读数与摘要均重新从 0 开始。

## 交付与主分支

构建产物为 dist/index.html 和 dist/assets/v04/，预览必须同时提供图片及素材清单。说明文档随仓库交付，现有构建不复制 docs 目录，可从 README 的文档入口阅读。

本轮完成本地集成、自动化测试和构建后，由可信交付桥在执行进程退出后处理真实提交、CI、未合并 PR 及预览。应以交付桥实际结果核实这些交付项；本轮没有创建或核实它们，也没有完成浏览器或本人验收。

主分支不自动合并，也不自动发布。PR 保持未合并，等待本人检查预览并验收最终版本；本地测试成功、技术交付或普通方案选择都不代表本人已验收或已授权合并发布。
